# SpecOps v0.4.5

**Release Date:** 2026-05-17

## Highlights

This release introduces **Health Score** — a single number that tells you if your agent is production-ready — and **Shareable Replay Sessions** — export, share, and import full replay sessions for collaborative debugging.

---

## ✨ New Features

### Health Score (`specops_ai.health`)

One number (0–100) that combines multiple reliability signals into a production-readiness score with letter grades (A–F).

- `compute_health_score()` — weighted score from loop rate, consensus, self-healing, chaos resilience, regression stability, memory integrity, and anomaly frequency
- `@health_check` decorator — auto-computes score after every agent invocation, raises `HealthCheckFailed` if below threshold
- `HealthReport` with score, grade, signal breakdown, and pass/fail
- `DEFAULT_WEIGHTS` — sensible defaults, fully customizable
- Full OTel integration — health checks produce spans

```python
from specops_ai import compute_health_score, health_check

report = compute_health_score(
    loop_rate=0.05,
    consensus=0.95,
    self_healing=0.90,
    chaos_resilience=0.85,
)
print(f"{report.score}/100 (Grade: {report.grade})")  # 89.2/100 (Grade: B)

@health_check(name="my-agent", threshold=70.0)
def agent(task: str) -> dict:
    ...  # Raises HealthCheckFailed if score < 70
```

### Shareable Replay Sessions (`specops_ai.replay`)

Export full replay sessions as portable JSON files — share with teammates, attach to bug reports, or archive for audits.

- `export_replay()` — bundles session with environment info, health report, chaos results, and regression data
- `import_replay()` — load and replay shared sessions
- `ReplayFile` dataclass — portable container with version, session, environment, and diagnostics
- Works with existing `recording()` / `replaying()` workflow

```python
from specops_ai import recording, replayable, export_replay, import_replay

@replayable
def call_llm(prompt: str) -> str:
    return "..."

with recording(session_id="debug-session", seed=42) as session:
    call_llm("What happened?")

# Export for sharing
export_replay(session, "bug-report.specops.json")

# Teammate imports and replays
replay_file = import_replay("bug-report.specops.json")
```
