## ✨ New Features

### Chaos Simulation (`specops_ai.chaos`)

Inject real-world agent failures into a simulation sandbox and verify that detection and self-healing work correctly.

- `ChaosEngine` — orchestrates fault injection with reproducible seeds
- Six fault types: hallucination, infinite loop, memory drift, tool failure, coordination disagreement, cascade failure
- `ChaosResult` with detection rate and healing rate metrics
- Full integration with the simulation sandbox

```python
from specops_ai import ChaosEngine, simulation

with simulation("chaos-test", max_steps=200) as sim:
    engine = ChaosEngine(sim, seed=42)
    engine.inject_hallucination("my-agent")
    engine.inject_infinite_loop("my-agent")
    result = engine.result()
    print(f"Detection rate: {result.detection_rate:.0%}")
```

### Automated Behavioral Regression Testing (`specops_ai.regression`)

Record golden agent runs and automatically detect behavioral drift in future runs — even when the final output looks identical.

- `golden()` context manager — record a golden behavioral trace
- `check_regression()` context manager — compare current run against golden
- `@regression_test` decorator — inline regression checks
- `compare_behavior()` — detect 5 drift types: step count, step order, tool usage, loops, timing
- `RegressionStore` — JSON persistence for golden runs
- `RegressionError` — raised when drift exceeds threshold

```python
from specops_ai import golden, check_regression, record_step

# Record golden run
with golden("baseline", agent_name="my-agent", task="summarize") as run:
    record_step("search", "tool_call")
    record_step("llm", "llm_call")
    run.final_output = "result"

# Check for regression
with check_regression("baseline") as result:
    record_step("search", "tool_call")
    record_step("llm", "llm_call")

assert result.passed  # True if behavior matches
```
