# SpecOps v0.2.0 — Simulation Sandbox & Multi-Agent Coordination

We're excited to announce **SpecOps v0.2.0**, adding two major capabilities to the Agent Reliability Kit: a simulation sandbox for testing emergent agent behaviors, and coordination checks for multi-agent systems.

## What's New

### 🧪 Simulation Sandbox

Test your agents for loops, cascading failures, and budget overruns *before* they hit production:

```python
from specops import simulation

with simulation("loop-test", max_steps=50, loop_threshold=3) as sim:
    for action in agent_actions:
        event = sim.record("my-agent", action)
        if event.anomaly:
            print(f"Caught: {event.anomaly.value}")
```

- **Loop detection** — Automatically flags repeated actions
- **Budget enforcement** — Max steps, duration, and token limits
- **`@simulate` decorator** — Run test scenarios with one decorator
- **OTel spans** — Every simulation produces traceable spans

### 🤝 Multi-Agent Coordination Checks

Built-in primitives for verifying multi-agent system health:

- **`check_consensus()`** — Verify agents agree (configurable quorum)
- **`check_memory_integrity()`** — Detect state divergence and stale reads
- **`check_divergence()`** — Flag behavioral drift via edit distance

### Integration

Both features integrate seamlessly with existing SpecOps modules:
- Record/replay inside simulations
- Run eval harnesses inside sandboxes
- Self-healing policies work within simulation contexts
