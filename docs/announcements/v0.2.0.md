# SpecOps v0.2.0

**Agent Reliability Kit** — Framework-agnostic, OTel-native toolkit for reliable, evaluatable, debuggable, and self-healing LLM agents in production.

## 🚀 Highlights

### Simulation Sandbox
Test your agents for loops, cascading failures, and budget overruns *before* they hit production.

```python
from specops_ai import simulation

with simulation("loop-test", max_steps=50, loop_threshold=3) as sim:
    for action in agent_actions:
        event = sim.record("my-agent", action)
        if event.anomaly:
            print(f"Caught: {event.anomaly.value}")
```

- Loop detection — automatically flags repeated actions
- Budget enforcement — max steps, duration, and token limits
- `@simulate` decorator for test scenarios
- Full OTel span integration

### Multi-Agent Coordination Checks
Built-in primitives for verifying multi-agent system health:

- `check_consensus()` — verify agents agree (configurable quorum)
- `check_memory_integrity()` — detect state divergence and stale reads
- `check_divergence()` — flag behavioral drift via edit distance

## ✨ What's New in v0.2.0

- **Simulation sandbox** with loop detection, budget enforcement, and cascade testing
- **Coordination checks** for consensus, memory integrity, and behavioral divergence
- **`@simulate` decorator** for declarative test scenarios
- **`SimulationEnvironment`** context manager with token tracking
- **Anomaly detection** (loops, drift, cascades, token overflow)
- **Integration** with existing trace/replay/eval/heal modules inside simulations
