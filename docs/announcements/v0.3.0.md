# SpecOps v0.3.0

**Agent Reliability Kit** — Framework-agnostic, OTel-native toolkit for reliable, evaluatable, debuggable, and self-healing LLM agents in production.

## 🚀 Highlights

### Strands Adapter

Full support for the [Strands Agents SDK](https://github.com/strands-agents/sdk-python) — trace tool-use agents with zero config:

```python
pip install specops-ai[strands]
```

```python
from specops_ai import trace_agent

@trace_agent(name="strands-research-agent")
def agent(task: str) -> str:
    # Your Strands agent logic — fully traced via OTel
    ...
```

The adapter auto-detects Strands and instruments tool calls, model invocations, and agent loops with OpenTelemetry spans.

### Provider Examples for Every Framework

Every provider (OpenAI, Anthropic, Grok) now ships with five complete examples covering all supported frameworks:

```bash
uv run examples/providers/openai/strands_agent.py
uv run examples/providers/anthropic/strands_agent.py
uv run examples/providers/grok/strands_agent.py
```

### Improved Test Coverage

187 tests passing at **96% coverage** — up from 120+ tests in v0.2.0. New tests cover the Strands adapter, edge cases in coordination checks, and simulation scenarios.

## ✨ What's New in v0.3.0
