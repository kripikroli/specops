# SpecOps v0.4.6

**Release Date:** 2026-05-17

## Highlights

This release introduces the **Visual Demo Runner** — a beautiful, browser-based UI for browsing, viewing code, and running all SpecOps examples with live streaming output. Run `specops-demo` and get an instant interactive showcase of every module.

---

## ✨ New Features

### Visual Demo Runner (`specops_ai.demo`)

A professional browser-based interface that auto-discovers and runs examples with real-time output streaming.

- `specops-demo` CLI command — launches the UI in your default browser
- **Dynamic discovery** — automatically scans `examples/` and shows all runnable examples (excludes `shared/`, `__pycache__`, `run_all.py`)
- **Sidebar** — example list with descriptions, module tags, and live ✓/✗ status indicators
- **Code Viewer** — read-only, syntax-highlighted source code for each example
- **Live Streaming** — real-time stdout/stderr via WebSocket as examples execute
- **Run All mode** — execute all examples sequentially with per-example pass/fail status (uses mock mode for safety)
- **Collapsible panels** — Traces, Health Score, and Replay Summary sections that auto-populate from output
- **Dark/Light mode** — toggle between themes
- **Future-proof** — auto-discovers any new examples added to `examples/` with no code changes needed

```bash
# Launch the visual demo runner
uv run specops-demo

# Custom port
SPECOPS_DEMO_PORT=9000 uv run specops-demo
```

### Run All Mode UX

When "Run All" is clicked:
1. Each example runs sequentially in mock mode (no API keys needed)
2. Sidebar shows live status: ⟳ (running) → ✓ (pass) or ✗ (fail)
3. Output panel streams all results with separators between examples
4. Final summary shows total passed/failed count
